I started using Claude Code without really knowing what I had in my hands. By trying things, making mistakes and discovering more, I found my rhythm until it became part of how I work. But at some point I asked myself an uncomfortable question: am I building on sand?

## Stop and go back to the start

So I stopped and did what I should have done from the beginning: Anthropic's *Claude Code 101* course.

I wasn't looking to learn something new, but to truly understand what I was already using, so that every decision had a reason behind it, not just a hunch.

## Fundamentals matter

Now I feel I have the foundations. Since then I've kept going with other Anthropic courses, such as *Claude Code in Action*, because I believe this is the way: build slowly, but build well. Mastering these tools and methods will be key for developers in the years ahead.

If you're just starting to develop with AI, my advice is this: don't skip steps. As with anything else, the fundamentals matter.
